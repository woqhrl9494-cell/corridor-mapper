METHOD & SCOPE

현재 SURF의 계산 범위

같은 12초 거리 기록으로 공유 곡면을 추정하고, 정반사 조건에서 접점을 계산합니다. 단일 그래프 형태의 원호와 사인 벽을 대상으로 합니다.

모델 후보
degree {2, 4, 6, 8}, λ {0, 1e−5}
선택 기준
원시 거리의 시간 block validation
최종 수락
거리 잔차, 모호성, 추정 곡면의 반사 조건과 가시성
수치 풀이
동결된 Python SURF / augmented QR

곡면과 참값의 비교는 계산이 끝난 뒤 평가에만 사용합니다. E0 점 교체 보정은 기본 출력에 포함하지 않습니다.

정확 대칭에서는 여러 가설을 유지하며 단일 벽으로 확정하지 않습니다. 가시성은 127개 내부 표본 검사이며 연속 기하의 완전한 보장은 아닙니다.

계산은 이 브라우저에서 수행합니다. 첫 실행에는 Python / NumPy 계산 엔진을 내려받으므로 인터넷 연결이 필요합니다. 이전 Corridor/Torus 및 3종 풀이기 비교는 별도 페이지에서 유지됩니다.
